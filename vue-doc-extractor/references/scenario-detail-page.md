# 详情页（多Tab）— 提取指南

## 提取清单

输出使用通用 UI 术语。

### 1. 页面入口与参数接收（关键）

追踪：从哪个页面/按钮进入 → 传了什么参数(id/type等) → 方式(params/query/Props) → 如何接收 → 如何用于数据加载

### 2. 主数据加载与响应结构（关键）

追踪：调哪个API、传什么参数、何时调用、响应结构(**详细记录前端使用了哪些字段**)

### 3. 页面头部/摘要区

标题来源、状态展示(值→文本→颜色映射)、摘要字段、返回按钮目标

### 4. Tab 结构

查找 `<a-tabs>`：各Tab标题/key、默认Tab、内容类型(描述列表/表格/时间线/自定义组件)、数据来源(主数据子字段/独立API)、是否懒加载

### 5. 各 Tab 内容详情

- **描述列表**：字段标签、数据路径、展示格式
- **表格**：列定义、数据来源、分页
  - **行操作列**：逐个记录每个操作按钮
    - 按钮文本、权限指令、可见条件（基于行数据字段判断）
    - 行为类型：跳转页面 / 打开弹框 / 打开抽屉 / 直接操作（删除、状态变更等）
    - 传递参数：传整行 record / 仅传 ID / 传多个字段
    - 目标：跳转路由 / 弹框组件名 / API 函数名
  - **行选择模式**：
    - 类型：单选 / 多选 / 不可选
    - 选择事件绑定方式（通用描述，不要写具体框架代码）
    - 已选数据存储位置
  - **批量操作**：
    - 出现条件（如：已选行数 > 0）
    - 操作按钮列表（文本、行为、确认机制如二次确认弹框）
    - 操作完成后的行为（清空选择、刷新列表等）
  - **行内编辑**：
    - 是否支持行内快速编辑
    - 可编辑字段列表
    - 编辑触发方式（点击单元格 / 切换编辑模式按钮）
    - 保存触发方式（失焦自动保存 / 手动确认）
  - **行展开**：
    - 是否有展开行
    - 展开内容结构（子表格 / 描述列表 / 自定义组件）
    - 展开数据来源（行内已有 / 额外查询）
- **时间线**：记录字段、数据来源
- **自定义组件**：组件名、Props、功能

### 6. 操作按钮与交互（关键）

每个按钮追踪：文本、位置、权限、可见条件、行为、**传递参数**、目标

### 7. 所有 API 契约

逐个记录，含完整请求参数和响应结构

### 8. 嵌套弹框/抽屉定义

**弹框清单**：逐个列出页面内所有弹框/抽屉
- 标识名称、触发来源（哪个按钮/链接）、容器类型（对话框/抽屉）、标题

**每个弹框的详细结构**：
- 触发方式：哪个按钮或链接触发，触发时传递哪些参数
- 数据来源：传入当前行 record / 仅传 ID 后额外查询 / 无需数据
- 内容类型：
  - 表单类（引用 scenario-form.md 的提取逻辑，按其字段清单格式记录）
  - 详情展示类（字段标签 + 数据路径 + 展示格式）
  - 确认操作类（确认文案 + 提交API + 提交参数）
  - 自定义组件（组件名 + Props + 功能说明）
- 如果是表单类弹框，需记录：字段列表、校验规则、提交API、提交参数组装
- 提交后回调：关闭弹框 + 刷新外层Table / 刷新整页 / 无操作 / 其他
- **嵌套层级**：如果弹框内还有子弹框，按层级递进记录（L1 → L2 → ...）

### 9. Tab 间联动关系

- **Tab 间数据依赖**：Tab B 的查询参数是否依赖 Tab A 中的选择或数据
- **Tab 切换刷新策略**：切换到某 Tab 时是否重新加载数据，触发条件是什么
- **共享状态**：多个 Tab 是否共享某些响应式状态（如主记录 ID、状态值）
- **联动触发**：某个 Tab 内的操作（如删除、编辑）是否需要触发其他 Tab 的数据刷新

## Tab 间联动

| 联动类型 | 说明 | 涉及 Tab |
|----------|------|----------|
| 数据依赖 | Tab B 的查询参数依赖 Tab A 中选中的记录 ID | A → B |
| 切换刷新 | 切换到 Tab C 时总是重新加载数据 | C |
| 共享状态 | Tab A 和 Tab D 共享主记录状态值 | A ↔ D |
| 操作联动 | Tab A 中删除操作后刷新 Tab B 列表 | A → B |

**详细说明**:
- **Tab B 数据依赖**: Tab A 中选择某行后，Tab B 自动以该行 ID 作为查询参数加载关联数据
- **Tab C 刷新策略**: 每次切换到 Tab C 都重新调用 API 获取最新日志数据
- **共享状态**: Tab A 和 Tab D 同时显示主记录状态，任一方触发状态变更后双方同步更新
- **联动触发**: Tab A 中执行删除操作成功后，自动触发 Tab B 列表刷新
