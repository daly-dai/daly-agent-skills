# 审批流页面 — 提取指南

## 提取清单

输出使用通用 UI 术语。

### 1. 页面入口与参数接收

同 detail-page，追踪从哪进入、传什么参数、如何接收。

### 2. 审批状态定义（关键）

查找状态常量/枚举/字典：所有状态值、显示文本、颜色映射。若无集中定义，从模板条件渲染反推。

### 3. 状态流转关系（关键）

从按钮可见条件和API调用推导：`哪个状态 --[什么操作]--> 哪个状态`

### 4. 审批步骤展示

如有步骤条：步骤列表(名称/角色)、当前步骤计算逻辑、状态确定逻辑、条件步骤

### 5. 审批操作按钮与数据流转（关键）

每个按钮追踪：文本/样式、可见条件(状态+角色/权限)、**审批人判断逻辑**、点击行为(直接API/打开弹窗)、传递参数

### 6. 审批弹窗/表单

各操作(通过/驳回/转办)的弹窗字段、必填规则、提交参数组装

### 7. 审批历史

展示方式(时间线/表格)、数据来源、每条记录字段

### 8. 业务内容展示

简述被审批数据展示方式、核心字段

### 9. 所有 API 契约

逐个记录，含完整请求参数和响应结构

## 接口契约

### 1. 加载详情 — `getApprovalDetail`
- 来源: `@/api/approval` | 方式: GET | 路径: `/api/approval/{id}`

**请求参数:**
| 参数名 | 类型 | 必传 | 说明 |
|--------|------|------|------|
| id | number | 是 | 路径参数 |

**响应数据:**
```
{
  data: {
    id, status, submitterId, currentApproverId,
    approvalHistory: [{ nodeName, action, approveTime, comment }],
    steps: [{ name, status, approverName }],
    // 业务字段...
  }
}
```

### 2. 审批操作 — `approveRequest` / `rejectRequest`
- 方式: POST | 路径: `/api/approval/{id}/approve` 或 `/reject`

**请求参数:**
| 参数名 | 类型 | 必传 | 说明 |
|--------|------|------|------|
| id | number | 是 | 路径参数 |
| comment | string | 否 | 审批意见 |
| rejectReason | string | 驳回必传 | 驳回原因 |
