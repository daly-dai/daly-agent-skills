# 整模块分析提取指南

本场景用于分析整个 CRUD 模块目录，自动识别目录下所有页面的场景类型，逐页面提取后合并为一份完整的模块文档。

## 提取清单

输出使用通用 UI 术语。

### 1. 模块目录扫描

**列出指定目录及其子目录下所有 .vue 文件**

按文件名模式识别场景类型：
- `list`、`index`、`List` → query-list（查询列表页）
- `form`、`add`、`edit`、`create`、`Form` → form（表单页）
- `detail`、`view`、`Detail`、`View` → detail-page（详情页）
- `approve`、`audit`、`flow`、`Approve` → approval-flow（审批流页面）
- 无法匹配的文件 → 标记为"待确认"，在输出中提示用户手动指定

**识别非 .vue 文件中的共享资源**
- 扫描 composable、hook、api、types、constants、utils 等目录/文件
- 记录文件路径和功能说明

### 2. 模块概述

- **模块名称**：从目录名推断或由用户提供
- **业务目的**：从页面内容推断模块的核心业务功能
- **包含的页面清单**：列出所有识别出的页面及各自的场景类型

### 3. 页面关系图

**分析页面间的跳转关系**（路由跳转、弹框打开等）：
- 追踪每个页面的入口来源（从哪个页面/按钮进入）
- 记录触发操作（点击、跳转、打开弹框等）
- 记录目标页面
- 记录传递参数（参数名、来源、传递方式）

**用文字描述或简单列表表达关系**，无需绘制图形

### 4. 逐页面提取

**按以下顺序依次提取**（保证先提取被依赖的页面）：

1. **查询列表页**（通常是模块入口）
2. **新增/编辑表单页**
3. **详情页**
4. **审批流页面**（如有）

**每个页面按其对应的 scenario-*.md 提取逻辑执行**：
- 查询列表页 → 按 scenario-query-list.md 提取
- 表单页 → 按 scenario-form.md 提取
- 详情页 → 按 scenario-detail-page.md 提取
- 审批流页面 → 按 scenario-approval-flow.md 提取

**如果同一场景有多个页面**（如多个不同的表单），逐个提取并标注区别

### 5. 跨页面数据流

**汇总所有页面间的参数传递关系**：
- 标识共享的数据（如同一个记录 ID 在多个页面间流转）
- 标识共用的 API（多个页面调用同一接口）
- 标识数据一致性要求（如编辑页修改后，列表页和详情页需要同步更新）

**追踪以下数据流模式**：
- 列表页 → 详情页：record.id 传递
- 列表页 → 编辑页：record.id 或整行数据传递
- 详情页 → 编辑页：id 传递
- 表单页提交后 → 列表页刷新

### 6. 共享资源

**列出模块内复用的文件**：

**Composable/Hook**：
- 功能说明
- 被哪些页面使用

**API 模块**：
- 导出的函数列表
- 被哪些页面调用

**类型定义**：
- 主要的 interface/type
- 被哪些文件引用

**常量/枚举**（参考 patterns-core.md 第8节）：
- **必须读取源文件并记录完整定义值**，不能只列常量名
- 每个常量记录：常量名、类型（映射/选项列表/枚举/配置/正则等）、完整定义、被哪些页面使用
- 用途说明
