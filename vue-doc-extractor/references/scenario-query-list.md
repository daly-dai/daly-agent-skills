# 查询列表页 — 提取指南

## 识别阶段（分析 Vue 源码，内部思考）

> 此阶段可以使用任何 Vue 术语定位代码，不会出现在最终输出中。

### 1. 搜索/筛选区域

找到页面中表单包裹的搜索区域，对每个表单项提取：
- 字段标签、字段名
- 控件类型（记录原始组件类型，输出时翻译——见输出阶段）
- 选项来源（参考 patterns-core.md 第 6 节）
- 业务含义

同时提取：搜索触发函数、重置行为、展开/收起功能。

### 2. 查询参数组装（关键）

追踪搜索触发函数内部（参考 patterns-core.md 第 5.5 节）：
- 字段如何映射为 API 请求参数
- 日期范围如何拆分
- 分页参数名和来源

### 3. 列表查询 API 契约（关键）

追踪主查询 API：函数名/路径/方式 → 入参结构（逐字段）→ 响应结构（列表路径 + 分页 + 每条记录的字段）。

### 4. 数据列表

找到数据列表组件及其列定义，每列提取：列标题、dataIndex、展示格式（纯文本/日期/状态标签/链接/操作按钮等）、特殊逻辑。

### 5. 操作列与页面交互（关键）

每个按钮追踪：文本、权限、行为类型、**传递参数**（传了 record 哪些字段）、参数传递方式、目标页面/组件。

删除操作额外记录：确认文案、API 入参、成功行为。

### 6. 工具栏/批量操作

列表上方或工具栏区域的按钮（新增/批量删除/导出），同样追踪参数传递。

### 7. 分页配置

分页参数名称（pageNo/pageSize）、默认分页大小。

### 8. 其他 API 契约

逐个记录：删除/状态变更/导出/选项加载 API，含完整入参和响应。

### 9. 常量与枚举（关键）

扫描所有从外部文件 import 的常量/枚举（参考 patterns-core.md 第 8 节），追踪到源文件读取实际值。重点关注：
- 状态/类型映射常量（用于列渲染、标签颜色等）
- 选项列表常量（用于搜索区下拉选项）
- 列定义常量（如果 column 定义从外部导入）
- 配置常量（分页大小等）

## 输出阶段（填 @FILL 标记）

> 🛑 输出前必须执行 Step 5 输出自检。所有输出必须翻译为框架无关术语，参照 `patterns-core.md` 第 9 节翻译表。

## @FILL 输出标记

### P0 标记（必须提取 — 数据 + API 契约）

```
@FILL:VALUE page_title [P0]
提示: 页面名称，从文件名和业务内容推断

@FILL:VALUE page_overview [P0]
提示: 一句话概述，含业务功能、管理什么数据、面向什么角色

@FILL:TABLE search_fields [P0]
提示: 搜索条件所有字段，无则填"无搜索条件"
列: 序号 | 字段标签 | 字段名 | 控件类型(通用术语) | 选项来源 | 业务含义

@FILL:TABLE query_param_mapping [P0]
提示: 搜索字段到接口参数的映射关系。直接传递的字段可合并为一行"以下字段直接传递: xxx, xxx"
列: 前端字段 | 接口参数 | 转换逻辑

@FILL:TABLE list_columns [P0]
提示: 数据列表所有列定义
列: 序号 | 列标题 | 数据字段 | 展示格式 | 备注

@FILL:TABLE operations [P0]
提示: 操作列所有按钮，逐行记录
列: 序号 | 按钮 | 权限 | 可见条件 | 行为 | 携带数据 | 目标

@FILL:BLOCK operations_detail [P0]
提示: 逐个说明每个操作按钮的完整交互流程（触发→确认→接口调用→成功后行为）。每个操作一段。

@FILL:BLOCK api_list_query [P0]
提示: 主列表查询接口契约。记录：函数名、请求方式(GET/POST)、请求路径、请求参数表(参数名|类型|必传|说明)、响应数据结构(前端实际使用的字段及路径)
```

### P1 标记（建议提取）

```
@FILL:TABLE toolbar [P1]
提示: 列表上方工具栏按钮（新增/批量删除/导出等），无则填"无工具栏"
列: 按钮 | 权限 | 行为 | 携带数据

@FILL:TABLE pagination [P1]
提示: 分页配置
列: 属性 | 值

@FILL:VALUE row_key [P1]
提示: 行标识字段名，如 id

@FILL:VALUE row_selection [P1]
提示: 行选择模式，填 无 / 多选 / 单选
```

### P2 标记（空间充足时提取）

```
@FILL:BLOCK api_other [P2]
提示: 除主查询外的其他接口契约（删除/状态变更/导出/选项加载等），每个按 api_list_query 格式记录

@FILL:TABLE constants [P2]
提示: 所有外部常量的完整定义。能静态确定的 → 内联实际值标注"[常量]"。无法确定的 → 标注"[待补充: 原因]"。参照 patterns-core.md 第 8.4 节提取边界。无则填"无外部常量"
列: 常量名 | 类型 | 提取状态 | 完整定义/待补充说明 | 用途

@FILL:TABLE data_model [P2]
提示: 当前页面涉及的数据实体定义。从接口响应和类型定义中提取字段信息
列: 字段名 | 类型 | 必填 | 说明
```

## 填充规范

1. **每个标记独立填充**，格式为：
   ```
   @FILLED:<id>
   <内容>
   @END
   ```
2. TABLE 类型：输出 markdown 表格体（不含表头），空单元格填 `-`
3. BLOCK 类型：自由文本，可用 markdown 列表、代码块
4. VALUE 类型：单行字符串
5. **🛑 禁止出现任何框架痕迹**（参照 `patterns-core.md` 第 9.7 节）
6. 无法确定的内容填 `待确认`，不要猜测
7. **所有枚举/常量值必须内联实际值**，标注 `[常量]`
