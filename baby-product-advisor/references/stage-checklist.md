# 分阶段母婴用品清单

> 所有建议基于中国家庭实际情况。标注使用周期，区分必需品/可选品/不必买。
> 当前适配：**2026 年 7 月出生（夏季宝宝）**。

## 使用周期图例

- 🟢 长期使用：6 个月以上（值得投资好的）
- 🟡 中期使用：2-6 个月
- 🔴 短期使用：< 2 个月（优先借/租/二手）
- ⚫ 一次性/消耗品

## 0-1 月清单（新生儿期）

**核心特征**：7-8 月盛夏，体温调节差，易长痱子/湿疹/红屁屁

### 新增必需品

| 物品 | 数量 | 季节备注 |
|------|------|---------|
| 空调恒温（24-26°C） | - | **比买什么衣服都重要**。非直吹、勤洗滤网 |
| 蚊帐（婴儿床） | 1个 | 物理防蚊，新生儿唯一安全方式 |
| 肚兜/肚围（薄棉） | 2-3条 | 空调房护肚 |
| 纸尿裤 S码 | 按需 | 约 8-10片/天 |
| 隔尿垫（可水洗） | 2-3块 | 换纸尿裤时垫 |
| 婴儿指甲剪（圆头） | 1把 | 新生儿指甲长得快，防抓脸 |
| 小夜灯（暖光、可调暗） | 1个 | 夜间喂奶用，不影响宝宝褪黑素 |

### 不必买（0-1月尤其不需要）

| 物品 | 原因 |
|------|------|
| 防抓手套 | 阻碍触觉发育。勤剪指甲即可 |
| 定型枕 | SIDS 风险，1岁以下不应用任何枕头 |
| 爽身粉（粉末状） | 吸入风险。用炉甘石洗剂替代 |
| 婴儿洗衣液（贵的） | 无香精无磷普通洗衣液即可 |
| 奶瓶消毒柜（紫外线） | 蒸汽消毒锅+晾干即可（100元内） |

## 高频"不必买"总清单

| 物品 | 为什么不必买 | 替代方案 |
|------|------------|---------|
| 婴儿专用水 | WHO/中国营养学会：白开水完全适合婴儿 | 白开水 |
| 婴儿酱油 | 1岁前不应加任何调味品；1岁后普通低盐酱油即可 | 1岁前不用，1岁后普通低盐 |
| 儿童牛奶（调制乳） | 含糖量通常高于纯牛奶 | 普通纯牛奶（2岁后） |
| 防辐射服 | 日常电磁辐射对胎儿无危害 | 不买 |
| 学步车 | 加拿大禁售，增加跌落风险，延迟行走发育 | 不买 |
| 定型枕 | SIDS风险，1岁以下不用任何枕头 | 不买 |
| 婴儿防抓手套 | 阻碍触觉发育 | 勤剪指甲 |
| 婴儿电动摇椅 | CPSC安全警告（倾斜睡眠产品） | 成人抱着安抚 |
| 婴儿洗衣液（贵价） | 成分与成人无添加洗衣液无明显差异 | 无香精无磷普通洗衣液 |
| 紫外线奶瓶消毒柜 | 蒸汽消毒锅+晾干足够 | 蒸汽消毒锅（<100元） |
| 奶瓶晾干架（专用） | 普通碗架一样用 | 普通碗架/厨房纸巾 |
| 湿巾加热器 | 湿巾离开包装就降温；夏季更用不着 | 不用 |
| 婴儿食盐/酱油/调味品 | 1岁前不加盐不加糖 | 天然食材本身味道 |

## 特殊场景调整

### 剖腹产额外准备
- 收腹带（医院通常会给，确认后再买）
- 高腰内裤（避免勒到伤口）
- 住院时间更长 → 多备 1-2 天护理用品

### 早产儿
- 衣物首选 44-48 码（正常新生儿从 52 开始）
- 额外保暖需求 → 医院通常提供暖箱指导
- 特殊奶瓶（早产儿奶嘴流速更慢）
- 严格遵医嘱，清单仅作方向参考
