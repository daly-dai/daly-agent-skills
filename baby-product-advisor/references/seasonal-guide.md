# 季节适配指南

> 当前适配：**2026 年 7 月出生（夏季宝宝）**。所有建议已按此自动适配。

## 7 月夏季宝宝核心特征

- 出生即盛夏（7-8月高温高湿）
- 新生儿体温调节能力极差 → 易长痱子/热疹
- 满月后仍处高温期（8-9月）
- 3-6 月龄处于秋冬（10-1月）
- 6-12 月龄处于冬春夏（1-7月）
- **核心原则**：宁可凉一点、不要捂。手脚凉 ≠ 冷，摸后颈判断。

## 分月龄服装指南

| 月龄 | 季节 | 室内穿着（空调24-26°C） | 外出/非空调 | 推荐数量 | 材质要求 |
|------|------|----------------------|-----------|---------|---------|
| 0-1月 (7-8月) | 盛夏 | 短袖连体衣 + 薄肚兜 | 短袖连体衣 + 薄帽遮阳 | 4-6件(汗湿勤换) | A类纯棉、单层、透气 |
| 1-3月 (8-10月) | 夏末初秋 | 短袖→薄长袖过渡，连体衣 | 加一件薄外套 | 各3-4件 | A类纯棉 |
| 3-6月 (10-1月) | 秋冬 | 纯棉长袖连体衣 + 夹棉连体衣(睡眠) | 加厚外出连体衣/睡袋 | 3-4套 | A类纯棉、夹层 |
| 6-12月 (1-7月) | 冬春夏 | 按实际温度：长袖→短袖 | 按季节+温度 | 每阶段2-3套 | A类 |

**穿多少的判断标准**：
- ❌ 不要摸手脚判断冷热（新生儿末梢循环差，手脚凉是正常）
- ✅ 摸后颈/后背：温热干燥 = 正好；凉 = 加一层；湿汗 = 减一层
- **捂热综合征是比着凉更危险的致命问题**

## 夏季（0-3月龄期间）核心护理

### 空调使用

| 问题 | 正确做法 | 错误做法 |
|------|---------|---------|
| 温度设置 | 24-26°C | 低于22°C或不敢开 |
| 风向 | 不直吹，用挡风板或调整百叶角度 | 直接对着宝宝吹 |
| 滤网 | **每月清洗** | 半年不洗（霉菌/尘螨） |
| 进出房间 | 先在门口过渡2-3分钟 | 忽冷忽热 |
| 湿度 | 保持 50-60%，可用加湿器（勤洗） | 过干（<30%） |

### 痱子（热疹）

| | 预防 | 治疗 |
|------|------|------|
| 核心 | 保持凉爽干燥 | 炉甘石洗剂（买不含薄荷脑的） |
| 衣物 | 纯棉透气、不穿太多 | 减少一层 |
| 沐浴 | 每天温水（37-38°C）冲凉 | 不搓洗痱子部位 |
| 禁止 | - | 不要涂油性护肤品、不要涂爽身粉、不要用花露水（酒精刺激） |

### 红屁屁（尿布疹）

| | 预防 | 治疗 |
|------|------|------|
| 更换 | 2-3小时换一次纸尿裤 | 更频繁更换 |
| 清洁 | 每次便后清水冲洗（不用湿巾擦） | 冲洗后轻轻蘸干（不擦） |
| 晾干 | 换新纸尿裤前屁屁完全风干 | 每天光屁股趴一会儿 |
| 护臀霜 | 氧化锌 15-25% 薄涂 | 氧化锌 15-25% 厚涂（像抹腻子） |
| 就医 | - | 3天未改善、出现水疱/溃破、伴随发热 |

### 蚊虫防护（新生儿 0-3 月）

| 方式 | 安全性 | 建议 |
|------|--------|------|
| 蚊帐 | ✅ 最安全 | **新生儿唯一推荐方式** |
| 长袖长裤 | ✅ | 薄款、浅色 |
| 电蚊拍 | ✅ | 物理灭蚊 |
| 驱蚊贴/手环 | ⚠️ 效果有限 | 不推荐 |
| 化学驱蚊（DEET/派卡瑞丁） | ⚠️ 3月龄以下不推荐 | 3月+可用低浓度DEET(≤10%) |
| 蚊香（燃烧式） | ❌ | 释放颗粒物 |
| 电蚊香液 | ⚠️ 室内密闭慎用 | 如使用需通风 |

### 阳光与防晒

| 月龄 | 防晒策略 |
|------|---------|
| 0-6 月 | 避免阳光直射。外出用推车遮阳篷+薄帽+长袖。**不用防晒霜** |
| 6 月+ | 可使用物理防晒霜（氧化锌/二氧化钛成分）。清洗即可卸除 |

## 秋冬（3-6月龄期间）核心护理

### 皮肤干燥/湿疹

| | 预防 | 处理 |
|------|------|------|
| 洗澡 | 水温 37°C以下、每次 < 10分钟、不用每次用沐浴露 | 洗澡后 3 分钟内涂润肤霜（"湿裹"效果） |
| 润肤 | 每天 1-2次全身涂抹 | 湿瘆期遵医嘱用激素，日常大量润肤 |
| 衣物 | 纯棉A类，不穿羊毛直接贴肤 | 纯棉打底 |
| 加湿 | 40-60% | 勤洗加湿器 |

---

## 春季（6-9月龄期间）注意事项

- 花粉/柳絮过敏原 → 外出后擦脸洗手
- 气温波动 → "洋葱穿衣法"（多层薄衣易穿脱）
- 手足口病高发季 → 勤洗手、玩具消毒
