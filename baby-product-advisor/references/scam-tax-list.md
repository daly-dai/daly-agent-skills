# 智商税避坑清单

> "母婴"不是品类，是定价策略。以下基于成分分析和价格对比。

## 智商税识别 — 5 个信号

一款产品符合 2 个以上信号，极大概率是智商税：

1. **成人世界不存在这个品类** → 婴儿酱油、婴儿水、婴儿盐、婴儿洗衣液
2. **商品标题含"婴儿专用"且价格是同材质普通品 3 倍以上**
3. **宣称功效违背儿科医学共识** → 定型枕、学步车、防辐射服
4. **小红书/抖音密集推广但循证医学平台(怡禾/丁香妈妈)无推荐**
5. **你需要专门买一件来"存放"它** → 奶瓶晾干架、湿巾加热器

## 食品类智商税

| 产品 | 宣称 | 事实 | 溢价 | 替代方案 |
|------|------|------|------|---------|
| 婴儿专用水 | 低钠、无菌、适合婴儿 | WHO/中国营养学会：白开水完全适合。商业无菌水冲奶粉 = 白开水烧开即可 | 1000%+ | 白开水（烧开后放凉至 70°C 冲奶粉） |
| 婴儿酱油 | 低盐、无添加 | 1岁前不应加任何调味品。1岁后普通低盐酱油即可 | 200-400% | 1岁前不用；1岁后普通低盐酱油 |
| 儿童牛奶/成长牛奶 | 专为儿童配方 | 本质是调制乳，糖含量常高于纯牛奶 | 50-150% | 2岁后喝普通纯牛奶 |
| 婴儿肉松/鱼松 | 高蛋白 | 钠含量极高，严重超标婴儿标准 | 100-200% | 自制无盐肉泥 |
| 儿童蜂蜜 | 更温和 | 1岁以下禁止任何蜂蜜（肉毒杆菌风险）；1岁以上普通蜂蜜即可 | 200%+ | 普通蜂蜜（1岁+） |
| 儿童面条/婴儿意面 | 细软、营养强化 | 成分与普通面条无本质差异，价格翻 3-5 倍 | 300-500% | 普通面条（煮软）、碎碎面 |
| DHA补充剂（藻油） | 促进大脑发育 | 母乳/配方奶已含足量DHA。额外补充效果缺乏高质量证据 | - | 母乳/含DHA配方奶已够 |

> **奶粉配方溢价**是母婴消费中智商税最密集的领域之一。OPO、乳铁蛋白、MFGM、A2、羊奶粉、"小分子"等卖点的溢价远超成本差异。详见 [formula-guide.md](formula-guide.md)。

## 用品类智商税

| 产品 | 宣称 | 事实 | 溢价 | 替代/建议 |
|------|------|------|------|---------|
| 防辐射服 | 防电磁辐射 | 日常电磁辐射对胎儿无危害（非电离辐射）。WHO/ICNIRP：无需防护 | ∞ | **不买** |
| 学步车（坐式） | 帮助学走路 | 加拿大已禁售。增加摔落/烫伤风险。延迟独立行走能力发展。AAP 明确反对 | - | **不买**。固定活动中心 > 学步车 |
| 定型枕 | 睡出好头型 | 美国儿科学会：1岁以下婴儿床上不应有任何松软物品，包括枕头。增加 SIDS 风险 | - | **不买**。多趴+换睡向自然圆头 |
| 婴儿防抓手套 | 防抓脸 | 阻碍触觉发育，影响大脑发育 | - | 勤剪指甲 |
| 婴儿电动摇椅/摇篮 | 安抚哄睡 | 倾斜睡眠产品，美国 CPSC 已发安全警告。婴儿应仰卧在平坦硬质床垫上 | 500-2000% | 成人抱着安抚。费雪 Rock'n Play 已被召回 |
| 奶瓶消毒柜（紫外线） | 彻底消毒 | 蒸汽消毒锅（加热水产生蒸汽）+ 自然晾干效果等同。紫外线可能加速塑料老化 | 300-500% | 蒸汽消毒锅（<100元）或直接开水煮沸 |
| 奶瓶晾干架（专用） | 卫生晾干 | 普通碗架/厨房纸巾无异 | 500%+ | 普通碗架 |
| 湿巾加热器 | 冬天暖和 | 湿巾离开加热器就降温；长期加热湿巾易滋生细菌 | - | 不用。手心捂一下即可 |
| 奶粉分装盒（转盘式） | 精准分装 | 普通小密封盒/储奶袋一样用 | 300%+ | 食品级小密封盒 |
| 尿布桶（专用密封桶） | 密封防臭 | 普通有盖垃圾桶 + 勤倒垃圾一样效果 | 500%+ | 有盖垃圾桶 |
| 婴儿床中床 | 防惊跳、好入眠 | 软边围挡增加窒息风险。AAP 反对任何形式的床围和床中床 | - | 襁褓睡袋（不包胯）+ 平坦硬床垫 |

## 护肤/清洁类智商税

| 产品 | 宣称 | 事实 | 替代方案 |
|------|------|------|---------|
| 婴儿专用洗衣液 | 温和无刺激 | 成分分析：与成人无香精无磷洗衣液无本质差异 | 成人无香精无磷洗衣液（如汰渍/碧浪基础款） |
| 婴儿柔顺剂 | 更柔软 | 柔顺剂会降低A类纺织品吸水性，且化学残留可能刺激皮肤 | **不用柔顺剂**。A类纯棉本身不硬 |
| 贵价婴儿润肤霜（¥200+） | 天然有机 | 核心保湿成分（甘油/凡士林/神经酰胺）与平价款一致。有机认证 ≠ 更安全 | 无香+斑贴测试通过+成分简单的平价款（如丝塔芙/适乐肤） |
| 婴儿按摩油（贵价） | 促进发育 | 矿物油(凡士林)是最安全不敏感的婴儿按摩油。贵价植物油可能致敏 | 无香矿物油/医用白凡士林 |
| 婴儿洗手液/泡沫洗手液 | 更温和 | 普通温和洗手液即可 | 普通温和洗手液 |

## 品牌溢价分析：母婴税最严重的品类

| 品类 | 母婴税幅度 | 具体例子 |
|------|-----------|---------|
| 婴儿护肤品 | 200-500% | 50ml面霜 ¥200+ vs 同成分成人品牌 ¥60 |
| 婴儿餐具（硅胶餐盘） | 150-300% | 母婴品牌 ¥150+ vs 同食品级硅胶普通品牌 ¥40 |
| 婴儿服装（A类） | 100-300% | 品牌连体衣 ¥150+ vs 白牌A类 ¥30-50 |
| 婴儿推车 | 100-500% | 高端进口 ¥8000+ vs 国产正规 ¥1500（同等功能安全） |
| 婴儿床 | 100-200% | 实木婴儿床 ¥2000+ vs 同木材普通儿童床 ¥800 |
| 辅食工具 | 200-400% | 辅食机 ¥500+ vs 料理棒 ¥150（功能一致） |
| 婴儿收纳（柜/架/箱） | 300-500% | 婴儿衣柜 ¥1000+ vs 普通收纳柜 ¥200 |

**核心原则**：看成分不看品牌，看材质不看包装，看标准不看宣传。

## 这些钱值得花（不一定是智商税）

| 产品 | 为什么值得 | 建议 |
|------|-----------|------|
| 安全座椅 | 生命攸关，好座椅=好标准=好安装设计 | 3C底线 + i-Size更优，但不用买最贵的 |
| 婴儿推车 | 每天用2-3年，推车好坏差异大 | 去实体店试！轻便+好收+轮子顺滑 > 品牌 |
| 纸尿裤 | 贴肤24h，差品牌真的红屁屁 | 不囤货，先买小包装试用不同品牌 |
| 婴儿床垫（硬质、透气） | 与SIDS直接相关 | 硬质床垫（不是软的！）+ 床笠 |
| 电子体温计（腋下/耳温） | 准确测温 = 正确就医决策 | 不要水银体温计！ |
| 吸奶器（双电动） | 背奶妈妈的生产力工具 | 不确定需求可以先租 |
